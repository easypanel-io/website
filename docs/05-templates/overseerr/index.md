# Overseerr

1-Click installation template for Overseerr on Easypanel

## Description

Overseerr is a request management and media discovery tool for the Plex ecosystem. It provides a clean, modern interface for users to browse and request content for Plex, seamlessly integrating with services like Sonarr, Radarr, and Jellyfin.

## Benefits

- Streamlined Media Requests: Allow users to easily request movies and TV shows through an intuitive interface
- Automated Content Management: Integrates with Sonarr and Radarr to automatically download and manage requested content
- User Management: Manage users with customizable permission levels for different request capabilities
- Plex Integration: Connect to your Plex server to track available content and viewing status

## Features

- Modern UI: Clean, responsive web interface built with React for desktop and mobile use
- Content Discovery: Browse popular and trending content from various streaming platforms
- Request Management: Review, approve, and manage user media requests in one place
- Email Notifications: Send automated emails for request status updates and new content availability
- Multi-language Support: Interface available in multiple languages through community translations
- Issue Reporting: Built-in system for users to report problems with media
