# Pixapop

1-Click installation template for Pixapop on Easypanel

## Description

Pixapop is a modern photo management and sharing application that provides a beautiful web interface for organizing, viewing, and sharing your photo collection. It features automatic photo organization, metadata extraction, and a clean, responsive interface for browsing your photos from any device.

## Instructions

You need to mount the photos volume to the container to make the application work.

## Benefits

- Photo Management: Organize and manage your photo collection with automatic organization, metadata extraction, and advanced search capabilities.
- Web-Based Interface: Clean and intuitive web interface accessible from any device with a browser for easy photo browsing and management.
- Photo Sharing: Share your photos with friends and family through secure links and customizable sharing options.
- Self-Hosted Control: Complete control over your photo collection with no external dependencies or data sharing with third parties.

## Features

- Web Interface: Modern web-based interface accessible from any device with a browser for easy photo browsing and management.
- Photo Organization: Automatic photo organization with folder structure management and intelligent categorization.
- Metadata Extraction: Automatic extraction of photo metadata including EXIF data, GPS coordinates, and camera information.
- Search and Filter: Advanced search and filtering capabilities to quickly find specific photos in your collection.
- Photo Sharing: Secure photo sharing with customizable access controls and sharing options.
- Responsive Design: Mobile-responsive design that works seamlessly across desktop and mobile devices.
- User Authentication: Built-in user authentication system with username and password protection for secure access.
- Data Persistence: All photo metadata, user settings, and configuration data persists across container restarts.
